# CROSSAIR-Missing-Scripts-Cleaner-PRO
Project Cleanup & Diagnostics PRO
Analyze. Find. Clean. Maintain your Unity project with confidence.
Over time, Unity projects can accumulate broken references caused by deleted or renamed scripts, removed assets, reorganized GameObjects, and other project changes.
Project Cleanup & Diagnostics PRO provides a centralized editor workflow for analyzing project health and locating common integrity issues across Scenes and Prefabs.
Instead of manually searching through large projects, scan your content, review detected issues, and quickly navigate to the objects that require attention.
🔍 Project Analysis
Scan your Unity project and get an overview of its current health.
Analyze:
Scenes
Prefabs
GameObjects
Missing Scripts
Missing References
Get a centralized view of detected issues instead of checking assets manually.
🧩 Missing Script Detection & Cleanup
Find GameObjects containing missing MonoBehaviour scripts across your project.
Missing scripts can appear after scripts are deleted, renamed, moved, or removed from a project.
The tool allows you to:
Scan Scenes
Scan Prefabs
Detect Missing Scripts
Review affected objects
Remove missing scripts in batches
Use Unity Undo to safely revert cleanup operations
🔗 Missing Reference Detection
Find serialized object references that are no longer valid.
The diagnostic system can identify broken references and show where they occur, including:
GameObject
Component
Property
Referenced object
Use the issue list to locate the affected object and inspect the problem directly in Unity.
❤️ Scene Health
Review the health of individual scenes with dedicated diagnostics.
For each analyzed scene you can see:
Objects scanned
Missing Scripts
Missing References
Total detected issues
Quickly select affected objects for further inspection.
📦 Prefab Health
Analyze prefab assets without manually opening every prefab.
Prefab diagnostics can identify:
Missing Scripts
Missing References
Affected GameObjects
Total detected issues
Useful for maintaining large libraries of reusable prefabs.
📋 Issue Analysis
Review detected problems in a centralized issue list.
Each issue provides information about its source and allows you to navigate directly to the affected object.
This makes it easier to move from:
Scan → Analyze → Review → Fix
without searching through the project manually.
⚡ Batch Processing
Designed for projects containing large numbers of scenes, prefabs, and GameObjects.
Scan and process project content efficiently instead of checking every object individually.
↩️ Undo Support
Cleanup operations use Unity's Undo system, allowing changes to be reverted when necessary.
This provides a safer workflow when removing missing script components from scenes and prefabs.
🛠 Editor-Only Workflow
Project Cleanup & Diagnostics PRO is an editor extension designed for project maintenance.
It does not add runtime systems or gameplay dependencies to your project.
